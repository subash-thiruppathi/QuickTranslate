Privacy Policy for QuickTranslate

Last updated: October 2026

1. Overview

QuickTranslate is built with a strong commitment to user privacy. We do not sell, track, monetize, or harvest any personal data. QuickTranslate functions strictly to provide on-demand translations for text you explicitly select on web pages.

2. Data Collection & Processing

  • No Personal Identifiable Information (PII): QuickTranslate does not collect your name, email, IP address, browsing history, or payment details.
  • Selected Text for Translation: When you select text and request a translation, that specific text string is securely transmitted over HTTPS to the translation endpoint exclusively to obtain the translated text and pronunciation. It is not tied to your identity.
  • Local Storage: Your configuration settings (e.g. default target language, dark mode preference) and optional recent translation history are stored entirely locally on your device via Chrome's storage API.

3. Permissions Justification

  • storage: Retains your selected target language and settings across browser sessions.
  • contextMenus: Allows right-clicking any highlighted text to quickly translate it.
  • activeTab: Provides interaction with the current webpage when initiating a translation.
  • https://translate.googleapis.com/*: Communicates with Google's translation service to fetch translations.

4. Third-Party Services

Translation requests are processed via Google Translate's public endpoint. The service operates under Google's standard privacy policies.

5. Contact & Support

If you have any questions or feedback regarding this policy, please reach out via the extension's support channels or GitHub repository.
